# CliffsCRM Field Desk

Locked visual system for the staffing CRM (2026-11-11).

## World

Calm **Field Desk** — Express Montgomery green ink, quieter lime accent, no mission/military/HUD cheese. Operate mode: one next action, then tools.

## Tokens

- Ink `#0b1511` · Paper `#f2f5f3` · Signal `#b8e84a` · Call `#0f6b55`
- Type: Syne (titles), DM Sans (UI)

## Surfaces

- **Home:** Next-up card + Now/Next/Later + stats + primary tools
- **Today:** Dial cockpit (Office) / Car HUD + travel add disclosure
- **MPC:** Fit leaderboard
- **Accounts:** Search first + Add travel
- **Q4:** Checklist wraps
- **Scout:** Signal feed path under More
