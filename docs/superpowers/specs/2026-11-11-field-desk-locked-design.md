# CliffsCRM Field Desk — locked design

**Status:** locked for implementation (replaces cheesy “mission / military / command deck” framing)  
**Date:** 2026-11-11 (America/Chicago)

## Verdict

Ship **Field Desk**: a calm staffing CRM that combines the best of the gallery — **next-action Home**, **Dial Cockpit + Car HUD**, **Fit Leaderboard MPC**, **Search-first Accounts**, **Checklist Q4**, **Signal Scout** — without orbit/radar/mission language.

## Combined picks (what we keep)

| Surface | Keep from gallery | Drop |
|---------|-------------------|------|
| Home | Mission Pulse *structure* (next card + stats + tools) | “Mission”, orbit, HUD chrome |
| Today Office | Dial Cockpit | Weinberg Theater as default; card-stack novelty |
| Today Car | Car HUD Navigate/Arrived | Dense reason text while driving |
| MPC | Fit Leaderboard | Match Radar |
| Accounts | Search First + Add travel | Dense ledger as default |
| Q4 | Checklist Focus | Celebration spam |
| Scout | Signal Feed path | Prospect Radar as default |

## Visual direction

- **Brand:** CliffsCRM / Express Montgomery still hero-level in the topbar.
- **Palette:** soft ink green `#0b1511`, paper `#f2f5f3`, accent lime `#b8e84a` (quieter), teal call `#0f6b55`.
- **Type:** Syne for titles, DM Sans for UI — keep.
- **Tone:** “Next call”, “Your day”, “Office / Car” — never Mission / Command / Orbital / Radar.
- **Motion:** 2–3 subtle transitions (hero appear, filter chip, dock press) — no glow storms.

## Home (most useful)

1. **Next** card — company, why, Call / Open Today.  
2. Compact dial/calls/visits strip.  
3. **Now / Next / Later** chips (Focus Strip idea): Now=Today, Next=Q4 or travel, Later=Scout/MPC.  
4. Primary tools (6): Today, MPC, Scout, Q4, Lists, Capture. Secondary behind More.
