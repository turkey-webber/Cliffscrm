# Company research dossier — design

**Goal:** For every book company (and ones added later), assemble staffing-relevant research Cliff needs before a call — and a Mike Weinberg opener — from verified data only.

## Hard rules

- Never invent phones, names, emails, pay, shift times, vendors, or approvers.
- Missing fields stay **Not on file** and appear in **Collect next**.
- Q4 appointments / planner locks untouched.
- Say associates, not temps. Goal of opener = appointment.

## Sources (priority)

1. **Q4 book** — Contact Summary contacts, last billed/contacted, badges  
2. **Timeline / notes / wrap-ups** — relationship history  
3. **Drop research** — Territory New Leads, Expeditor inbox, company briefs, Scout jobs  
4. **ZoomInfo people CSV** — decision-maker rows already imported  
5. **Optional Grok** — organize/summarize **only** the snapshot sent; rewrite Weinberg opener; never add new CRM facts  

External boards (LinkedIn, Talent.com, Indeed, AIDT, Chamber) stay as **research links** Cliff opens; crawlers are blocked.

## Dossier fields

| Field | Fill from |
|-------|-----------|
| Decision makers | contactName/title + ZoomInfo/research lines naming people |
| Current job postings | research facts dated ≤90d with hiring language |
| Previous postings | older hiring facts |
| Staffing bio | short summary from verified research + badges (no invention) |
| Hiring signals | expansion/posting/turnover facts |
| Business changes | expansion, plant, ownership, relocation facts |
| Relationship history | last contacted/billed, timeline, notes |
| Shift schedules | only if notes/research state them |
| Staffing vendors | only if notes/research name competitors/vendors |
| Hiring approver | only if titled/named as such on file |
| Weinberg opener | Relevant → Relatable → Results → appointment ask |
| Collect next | deduced gaps |

## UI

- Company card → **Research dossier** panel + **Build / Enrich**  
- More → **Research book** — batch-build local dossiers for all companies; optional Grok enrich one-at-a-time  
- Dial desk already shows research strip; opener uses dossier Weinberg when present
